Introducción

Esta es la entrega final de la asignatura "Imagen Escrita" realizada en el segundo semestre del año 2026, en la cual se tuvo la introducción a la programación como diseñadoras y diseñadores, partiendo con el uso de el sitio web "P5js", donde se realizaron los primeros encargos acercamiento al lenguaje javascript.

Para esta última entrega se tuvo que hacer uso de archivos HTML y CSS, los cuales fueron editados en base a un "Wireframe" inicial, el cual se le hizo entrega a un asistente de Inteligencia Artificial para plasmarlo en código, el cual tuvo que ser supervisado para dar un resultado acorde con la visión de diseño que se tuvo.

Alexander
Hamilton

La creación de un primer proyecto en P5js, una prueba de las formas que se pueden crear, los colores aplicables y uso de las coordenadas

¡Boom!

En la primera creación de un código complejo se partió desde un bosquejo inicial, pero con la ayuda de Inteligencia Artificial se llega a un resultado adelantado a la materia.

Sparkles

Se pasa a un código más “artesanal”, usando funciones ya vistas como “seno”, “coseno”, “frameCount”, variables, modos de ángulo que crean desde la rotación de las formas, como se agrandan, giran, parpadean, respiran, cambian de color y demás.

Sneaky Snake

Se aplica funciones tanto de seguimiento de mouse, como sliders para generar una suerte de serpiente geométrica, pudiendo personalizar su tamaño.

Partículas

En base a un ejemplo visto en clases se modifica y crea una repetición de partículas ascendentes con una forma personalizada, referencia a la serie Jojo’s Bizarre Adventure.

Juego de
semillas

Como proyecto final se creó una composición que recopila distintas funciones y elementos aprendidos durante la unidad.
